# VOXO

VOXO — кинотеатр для Android TV, Android и Desktop.

Бесплатный. Без рекламы и подписки.

Каталог, поиск и просмотр — в одном приложении.
Поддерживает онлайн-воспроизведение и P2P-источники, включая видео в 4K, HDR и с многоканальным звуком.
Не требует собственного медиасервера или сложной настройки.
