# VOXO

VOXO — локальный P2P-медиаплеер для Android TV, Android и Desktop.

- Бесплатный.
- Без рекламы.
- Не требует подписки.
- Видео воспроизводится из исходного P2P-файла без дополнительного серверного перекодирования.
- Поддерживает высокое качество источника, включая 4K, HDR и многоканальный звук.
- Не требует собственного медиасервера или CDN.
- Основная логика работает локально на устройстве.
- Позволяет начинать просмотр до полной загрузки файла.
- Каталог, поиск источника и воспроизведение объединены в одном интерфейсе.
